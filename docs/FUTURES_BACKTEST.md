# 個股期回測（實單績效＋What-if 出場模擬）

左側導覽「個股期回測」。程式：`tradingnote_futures_backtest.py`（計算、匯入）、`ui/pages/futures_backtest_page.py`（頁面）、
`tradingnote_taifex.py`（期交所日 K）。交易紀錄跟股票共用 `trades`／`trade_executions`，`instrument='SSF'`。

## 每天怎麼記

**手動**：「部位紀錄」→ 新增部位，「商品」選「個股期 標準型（2000 股／口）」或「個股期 小型（100 股／口）」，
代號填**標的股票代號**（2330），合約月份預設近月，期貨代號會從期交所清單自動帶（CDF／QFF，可改）。
之後加碼、減碼、平倉都用「新增成交」，期交稅（十萬分之二）自動算、可手改。平倉到 0 口自動結案。

**CSV**：本頁「匯入 CSV…」。範本用「下載範本…」取得，欄位：

| 欄位 | 必填 | 說明 |
|---|---|---|
| 日期 | ✓ | `YYYY-MM-DD`，可加 `HH:MM`；斜線亦可 |
| 標的代號 | ✓ | 股票代號，如 `2330` |
| 合約 | ✓ | `標準型` 或 `小型` |
| 合約月份 | ✓ | `YYYYMM` |
| 買賣 | ✓ | `買`／`賣` |
| 口數、價格 | ✓ | |
| 手續費 | | 預設 0 |
| 期交稅 | | 留空自動算 |
| 策略 | | 不存在會自動建立 |
| 停損價 | | 留空＝未設停損（R 倍數顯示 —） |
| 備註 | | |

配對規則：同一（標的, 合約型, 月份）依時間排序，空手時開新交易、同向加碼、反向減碼，反手時拆成平倉＋新倉（手續費／稅依口數比例拆）。
重複匯入同一檔案會跳過已匯入的列；檔案有任何一列格式錯誤就整份不匯入。UTF-8 或 Big5 皆可。

## 實單績效

只算已平倉交易，依**最後一筆出場日**歸屬。淨損益＝價差×口數×每口股數－手續費－期交稅。
指標：總淨損益、勝率（淨損益 > 0 才算贏）、盈虧比（均賺÷均賠）、獲利因子（總賺÷總賠）、每筆期望值、
最大回撤（權益曲線距前高最大跌幅）、最大連虧、平均持有天數、平均 R（有設停損的才算）。另有月別、多空、策略分組。

## What-if 出場模擬

保留實際進場，換成指定的出場規則，用期交所該合約月份的**真實日 K**重算，跟實際結果比較。
規則可組合：停損（固定 %／原計畫停損價）、停利（固定 %／R 倍數）、移動停損 %、最多持有 N 天；全不設＝抱到到期。

假設：
- 進場＝實際第一筆進場日、全部進場口數的均價（加碼視為同日進場）。
- 從進場**隔天**的 K 開始檢查（當天盤中先後未知）。
- 開盤跳空越過停損／停利以開盤價成交；同一根同時碰到停損與停利**保守當作先停損**。
- 移動停損用前一根為止的最高（多）／最低（空）價。
- 到期日（到期月份第三個星期三，不處理假日順延）以結算價出場；K 用完仍未到期標「未到期（最新收盤）」。
- 只用日盤（一般）K，夜盤不納入。手續費沿用實單，期交稅依模擬出場價重算。
- 抓不到 K 的交易（沒有期貨代號、無資料）兩邊都不納入統計，逐筆表會註明。

## 期交所資料

- 日 K：`https://www.taifex.com.tw/cht/3/futDataDown`，POST `down_type=1&commodity_id=CDF&queryStartDate=YYYY/MM/DD&queryEndDate=…`，
  Big5 CSV，單次跨度實測 31 天可、61 天回 HTML（2026-11）。存 `futures_daily`，已查過的曆日記在 `futures_daily_checked`，不重抓；
  今天的日子只有抓到資料才算查過。第一次模擬會連網下載，之後用本機資料。
- 期貨代號：`SSFLists`（openapi）。清單沒標哪個是小型；同一標的有兩個契約時，小型一律排在後面（實測 53 檔皆如此），依此判斷。
