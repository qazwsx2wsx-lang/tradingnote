# TradingNote

一個在自己電腦上執行的台股桌面工具：記錄持股、看資金往哪些產業流、查個股籌碼、看期貨盤後行情，順便寫交易筆記。

資料全部來自公開來源（證交所、櫃買中心、期交所，以及選用的 FinMind），用的是**每天收盤後的資料，不是即時報價**。所有資料都存在本機的 `data/` 資料夾，不會上傳到任何地方。

---

## 怎麼開始用

需要 **Python 3.12**。請不要用其他版本：較新的 Python 會拒絕證交所網站的憑證，導致抓不到資料。

- **Windows**：雙擊 `啟動TradingNote.bat`。第一次執行會自動建立環境、安裝套件。
- **macOS**：雙擊 `啟動TradingNote.command`，或在終端機執行：
  ```bash
  /opt/homebrew/bin/python3.12 tradingnote_gui.py
  ```

選用設定：

- **FinMind Token**：個股的本益比、三大法人、融資融券等詳細資料要用到它。目前要手動寫進 `data/settings.json` 的 `finmind_token` 欄位（見下方「已知問題」）。
- **「法人資金流去哪？」頁的歷史資料**：要先回補一次才會有內容，可以按頁面上的「更新法人資料」，或執行 `scripts/backfill.py`。也可以設定每天自動更新，說明在 [`scripts/README.md`](scripts/README.md)。

## 功能

程式左側是導覽列，共七個頁面：

| 頁面 | 可以做什麼 |
|---|---|
| **資金流向** | 用泡泡圖看各產業今天的資金動向。每顆泡泡是一個產業，位置代表漲跌和成交量放大的程度；可切換「動能」「估值」「主力同步買超」三種看法。點泡泡會列出該產業前十大個股。下方另有資金流入排行、成交量異常的個股清單，以及外資／投信／自營商各自在買賣哪些產業。 |
| **法人資金流去哪？** | 專門看三大法人。每天盤後一句話總結，加上法人買賣排行、近 5 日動向、類股熱力圖；點任一類股可以看它過去 30 天的進出和成分股。 |
| **部位紀錄** | 記錄自己的持股（代號、股數、成本），自動算出現值和損益。選取一檔持股，下方會顯示它的籌碼趨勢圖。 |
| **交易週誌** | 以週為單位，每天一張卡片，顯示持股總值的變化和當天變動最大的股票，並可以寫當天的交易筆記。切換日期或關閉程式時會自動存檔。 |
| **個股查詢** | 依產業列出全市場約 1,700 檔股票，可以搜尋。選一檔會顯示趨勢、動能、量價背離等簡單判斷；雙擊打開詳細視窗，有 8 張籌碼圖（股價、三大法人、融資融券、借券…）和 24 種技術指標。 |
| **期貨行情** | 期交所全部期貨商品的盤後行情，以及大額交易人（前 5／前 10 大）的留倉部位和歷史趨勢。 |
| **設定** | 開機自動檢查資料是否齊全、設定歷史資料要回補幾天、手動回補。 |

另外有一個簡單的命令列版本（`tradingnote.py`），只有部位紀錄和資金流向功能。

## 架構

整個程式分成三層，原則是**「計算」和「畫面」分開**：計算的程式完全不知道畫面長什麼樣子，所以同一套計算可以同時給桌面程式和命令列版本使用。

```
外部資料來源（證交所、櫃買中心、期交所、FinMind）
        │
        ▼
共用工具        負責上網抓資料、快取、決定檔案放哪裡
        │
        ▼
核心功能        負責計算：損益、資金流向、技術指標、法人統計、週誌…
        │       （tradingnote_*.py，只用 Python 內建功能，不需要額外套件）
        ▼
介面            負責顯示：桌面程式（tradingnote_gui.py + ui/）、命令列（tradingnote.py）
```

### 主要檔案在哪裡

| 位置 | 內容 |
|---|---|
| `tradingnote_core.py` | 持股資料、即時查價、損益計算、本機設定 |
| `tradingnote_history.py` | 股票歷史價格資料庫、產業分類、資金流向計算 |
| `tradingnote_flow.py` | 把資金流向的各種計算整合起來，給「資金流向」頁用 |
| `tradingnote_institutional*.py` | 三大法人買賣超（當日＋逐日歷史） |
| `tradingnote_finmind.py` | FinMind 資料（本益比、融資融券、借券…） |
| `tradingnote_taifex.py` | 期貨行情與大額交易人 |
| `tradingnote_technical.py` | 技術指標計算（均線、KD、MACD、RSI…） |
| `tradingnote_journal.py` | 交易週誌 |
| `tradingnote_gui.py` | 桌面程式的進入點與主視窗外框 |
| `ui/tabs/` | 各頁面的實作，一頁一個檔案 |
| `ui/dialogs/` | 各種彈出視窗（個股詳細、新增持股、回補進度…） |
| `ui/charts/` | 泡泡圖、籌碼圖等圖表 |
| `ui/components/`、`ui/theme.py` | 共用的畫面元件和配色（深色主題，台股慣例漲紅跌綠） |
| `scripts/` | 法人資料回補和每日自動更新的腳本 |
| `tools/` | 維護用的小工具（重建概念股清單、效能測試…） |
| `data/` | 執行時自動產生：持股、設定、快取、歷史資料庫（不會進版本控制） |

### 資料怎麼存

- **設定與持股**：`data/` 底下的 JSON 檔。
- **歷史資料**：全部放在同一個 SQLite 檔 `data/history.db`。每個核心模組各自管理自己的資料表，不去動別人的。
- **網路資料**：會在本機快取一段時間，網路斷線時退回使用舊資料，畫面不會整個空掉。

更深入的設計說明在 [`ARCHITECTURE.md`](ARCHITECTURE.md)。

## 開發中的事項

### 正在進行

- **畫面程式拆檔（已合併進 main）**：原本 5,400 行的 `tradingnote_gui.py` 已拆成 `ui/` 底下按頁面、視窗、圖表分類的小檔案。只搬位置、不改功能，自動測試結果與拆之前相同；**還差實際開程式逐頁點過確認**。
- **畫面設計系統**：逐步把各頁換成統一的卡片、標籤、提示元件。目前每種元件只用在一兩個地方，還沒推廣到全部頁面。

### 已知問題

- **「設定」頁沒有填 FinMind Token 的欄位**，但程式裡有提示叫使用者去那裡填，會讓人找不到。目前只能手動改 `data/settings.json`。
- **「主力同步買超」泡泡圖**：只有選取的日期區間每天都已回補過，才是整段期間的加總，否則只用最新一天；畫面上沒有標示目前是哪一種。
- **泡泡大小**目前依成交金額決定，小型股即使爆量也不明顯。
- **產業顏色**由名稱自動決定，分類一多偶爾會有兩個產業顏色太接近。
- **程式偶爾閃退**的問題已用暫時解法擋住（關閉 Python 自動記憶體回收），但還沒百分之百確定原因。
- 自動測試中有 1 項（`test_tradingnote_flow_gui`）長期失敗，與最近的改動無關，尚未修。
- 命令列版本沒有「個股」和「期貨」功能。

### 之後可能做

- 左側導覽列分組（市場／分析／交易／資料），首頁改成「先看重點、需要再展開」的儀表板。
- 把各頁從目前的拆檔方式，進一步改成彼此獨立的頁面元件。
- 圖表配色統一到主題設定裡。
